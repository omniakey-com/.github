## AI Agent API Setup

Generate configuration for Claude Code, Codex, OpenClaw, Hermes Agent,
OpenCode, Cursor, Cline, and Aider from one provider-neutral tool.

- Interactive static configurator with shareable client and protocol choices
- Installable Agent Skill and zero-dependency Node.js CLI
- Local model-list probe that reads API keys only from environment variables
- OpenAI Chat, OpenAI Responses, Anthropic Messages, and Gemini-aware contracts

The web configurator never asks for an API key and makes no LLM API requests.
